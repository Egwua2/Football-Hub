# FOOTBALL HUB

Football Squad Building, Battles and Interactive Football Games Platform

Football Hub is a football-based web application designed to allow users to build and customize football squads, create their Ultimate XI, select managers, compete against other squads, and take part in different football-related games and challenges.

The system combines squad building, player ratings, manager selection, squad battles, multiplayer features, challenges, and interactive football games into one platform.

## Project Objective

The objective of Football Hub is to develop a practical and interactive football platform where users can create their own squads, compare their teams, compete with other users, and participate in football-themed activities.

The system is designed with a React frontend, Spring Boot backend, and MySQL database.

## Project Architecture

Football Hub uses a frontend and backend architecture where the React application handles the user interface, squad building, player selection, formations, and other user interactions.

The Spring Boot backend manages the main application services, REST APIs, business logic, and communication with the MySQL database.

The project also uses TheSportsDB API to retrieve football player information.

The planned multiplayer and battle features will allow users to create squads and compete against other players through the Football Hub platform.
